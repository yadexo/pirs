You are a senior full-stack engineer and product designer. Build a production-ready white-label sales, loyalty, membership, and customer engagement application for clinics and practices.

Do not use the name “Dermis” anywhere in the codebase, interface, metadata, documentation, database, seed data, or placeholder content.

The application must be suitable for clinics and practices in general. Do not position it specifically for medspas or any single medical specialty.

## Working method

1. Inspect the existing repository before making changes.
2. Identify the current framework, architecture, database, authentication system, styling approach, and coding conventions.
3. Reuse the existing stack wherever practical.
4. Do not replace working infrastructure unnecessarily.
5. Create a clear implementation plan before editing files.
6. Implement the application in logical phases.
7. Run the available linting, type-checking, testing, and build commands after implementation.
8. Fix all errors caused by your changes.
9. Do not leave core features as static mockups or non-functional buttons.
10. Where external services require credentials, create a functional local abstraction, environment-variable configuration, and documented integration point.

If the repository is empty, use this default stack:

* Next.js with TypeScript
* App Router
* Tailwind CSS
* PostgreSQL
* Prisma ORM
* Secure email-and-password authentication
* Role-based access control
* Stripe-compatible payment architecture
* Responsive web application designed to feel like a mobile app
* Accessible reusable component system

## Product objective

Create a multi-tenant white-label platform that gives each clinic or practice its own branded customer application and business administration dashboard.

Customers must be able to:

* Browse services, products, packages, and promotions
* Purchase services and packages
* Join monthly or annual memberships
* Earn and redeem loyalty rewards
* View their account credit and purchase history
* Receive promotional notifications
* Manage their profile
* View upcoming and previous appointments
* Communicate with the clinic or practice

Clinic and practice staff must be able to:

* Configure their branding
* Manage services, products, packages, and pricing
* Create membership plans
* Configure loyalty rules and rewards
* Manage customers and leads
* Create promotions
* Send notifications
* View purchases, payments, memberships, and customer activity
* Manage appointments
* View business performance metrics
* Manage staff access and permissions
